CLI Workflow, DTO-to-UI & Executable Proof Gate

Zero Node.js, zero PostCSS, zero Vite plugins required. Compile OKLCH CSS, scaffold DTO forms and tables, launch the local Token Studio, and mathematically prove accessibility & bundle budgets from one PHP binary.

1. Install, Scaffold & Tree-Shake

composer require kongono/zokeibi

# Initialize project tokens (zokeibi.json)
php vendor/bin/zokeibi init --theme=sumi

# Copy owned <x-ui.*> templates into views/components/ui/
php vendor/bin/zokeibi add button card chart editor tree password-input
php vendor/bin/zokeibi block add saas-shell analytics-dashboard

# Generate forms & sortable tables directly from PHP 8.5 DTOs
php vendor/bin/zokeibi form App\\Dto\\CreateOrderInput --out=views/orders/form.kgn.html
php vendor/bin/zokeibi table App\\Dto\\OrderRow --out=views/orders/table.kgn.html

# Pure PHP CSS tree-shaker + optional zero-dependency strict-CSP runtime
php vendor/bin/zokeibi build --views=views --out=public/assets/zokeibi.min.css
php vendor/bin/zokeibi runtime --out=public/assets/zokeibi-runtime.js

# Local OKLCH Design Token Studio GUI (with Live Hot-Swap Sync)
php vendor/bin/zokeibi studio --dir=. --port=8101

2. Executable UI Proof Certificate

$ php vendor/bin/zokeibi prove --dir=. --views=views --strict

Built for Kongono — Zero Lock-In on Any Stack

kongono/zokeibi requires only PHP >= 8.5.13 with zero runtime Composer dependencies. Use it directly with Kongono Live 2.5 or export tokens and tree-shake .z-* classes across HTML, HTMX, Twig, Blade, React, Vue, and Svelte.
